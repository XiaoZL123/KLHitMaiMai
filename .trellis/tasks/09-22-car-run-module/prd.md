# 底盘运动解算、OPS 位姿闭环与蓝牙控制

## Goal

通过 `car_run.c/.h` 封装麦克纳姆运动学与四轮同步速度发送，在 `car_control.c/.h` 使用 OPS 完成位置和航向闭环。上电以首个有效位姿为零点；位移命令在上次目标上累加，到位后持续保持。蓝牙支持位置命令和开环/闭环切换。

## Background and Confirmed Facts

- 电机轮位固定：左前 1、右前 2、左后 4、右后 3，逻辑轮速符号依次 `+1/-1/+1/-1`。轮径 `100 mm`，当前 `main.c` 左右中心距及前后中心距均为 `0.2 m`，实际几何仍待标定。
- `car_run.c/.h` 已加入 CMake，提供初始化、车体速度解算、四轮同步发送与停止接口；输入单位为 m/s、m/s、rad/s，正方向为前进、左移、逆时针。
- `SoftWare/BIGDICK/Core/Inc/test.h` 原 `C` 速度输入范围为 ±1000，映射上限为平移 `0.5 m/s`、旋转 `2.0 rad/s`；本次速度上限沿用这组数值。
- `SoftWare/BIGDICK/Core/Src/ops.c` 原新鲜度接口只检查 `heading/z` 有限及数据年龄 `<= 50 ms`，X/Y 尚未参与有效性判断。
- OPS 手册 3.3、3.4.4、4.1、4.2 节确认：X/Y 单位 mm、角度单位 deg、约每 5 ms 输出一帧，采用绝对坐标；推荐传感器 Y 朝前、X 朝右、中心与底盘中心重合。实际安装偏角、中心偏移及航向正方向尚未由硬件验证。
- `SoftWare/BIGDICK/Core/Inc/car_control.h` 当前用户调参为航向 `Kp=3.0`、`Kd=0.4`、死区 `1 deg`，不得被旧任务记录覆盖。
- TIM6 每 5 ms 中断置位 OPS 待处理标志；USART2 循环 DMA/IDLE 接收；主循环依次消费 OPS、FDCAN、蓝牙，再按周期执行控制。中断不做闭环解算或 CAN 发送。
- 工作区包含大量已有改动；保留无关文件和用户参数，不自动提交、烧录或驱动车辆。

## Requirements

### R1：底盘与周期边界

- 保留独立 `CarRun` 运动学层，不引入 OPS 依赖。四轮按地址 1、2、4、3 发送同步缓存速度，全部成功后广播一次 `X42S_SyncStart()`。
- 几何、轮速限幅、加速度及轮向集中配置；非法输入、未初始化和 CAN 错误有明确状态返回。
- 浮点控制和电机发送在主循环中进行，每次消费 TIM6 5 ms 节拍最多更新一次，不补发历史周期。
- 公开接口、对应 `.h/.c` 职责与简短中文函数注释同步维护；新增源文件须加入 CMake。

### R2：启动零点与持续保持

- `CarControl_Init()` 默认选择位置闭环；首个有效 OPS 位姿到达前不产生闭环运动输出。
- 在首个有效位姿建立启动零点和初始目标 `(0,0,0)`；捕获后不因数据恢复、蓝牙失联或模式切换自动重置零点。
- 目标只由位移接口成功调用改变；目标到达后继续纠偏保持，不依赖持续蓝牙输入。

### R3：位移指令语义（用户已选择 A）

- 提供三参数接口 `CarControl_Move(dx_mm, dy_mm, dangle_deg)`。
- X 为启动时车头方向，Y 为启动时左侧方向，角度正值逆时针；坐标方向固定，不随之后转向改变。
- 三个参数累加到上一次目标。连续两次 `(500,0,0)` 的最终目标为 `(1000,0,0)`；正在移动时的新指令也累加到目标，不以当前实际位置替代。
- 角度增量为实际有符号转动量，支持跨越 ±180 deg 及整圈；持续展开 OPS 航向，避免把 `+270 deg` 命令变为 `-90 deg`。
- 未初始化、零点未就绪、非有限参数、目标数值溢出或非闭环模式时拒绝位移请求，保持目标不变。

### R4：开环/闭环模式

- `CarControl_SetMode()` 切换开环和位置闭环；`CarControl_GetMode()` 查询模式。
- 开环完全旁路位置与航向纠偏，只执行手动速度目标，不因 OPS 不可用而更改该速度；速度失联仍停车。
- 闭环只接受位置目标，原 `C` 速度帧不得修改模式或闭环目标。
- 模式切换先停止旧输出、清空手动速度，保留零点与位置目标；切回闭环后追踪保留的原目标。重复设置同一模式不改变状态。
- `CarControl_Stop()` 作为显式停用入口，保留位置目标但禁止周期输出；新有效命令或显式模式切换可重新启用。

### R5：闭环控制、有效性与速度上限

- 平移采用位置比例控制，接近目标时减速；位置和角度死区作为头文件可调宏。
- 航向采用当前 PD 参数，沿用 OPS Z 轴角速度阻尼反馈。
- 平移合速度限幅 `0.5 m/s`，避免对角运动超过原速度值 1000 的上限；旋转输出限幅 `2.0 rad/s`。
- 闭环要求 X/Y/航向/角速度均有限，且最新位姿年龄不超过 50 ms；数据无效或超时立即停止输出，保留零点、目标和模式。
- 有效数据恢复后继续原目标，不沿用旧的航向重捕获行为；长时间丢帧期间的整圈转动无法仅凭 OPS 的 ±180 deg 输出重建，应列为物理验证限制。
- 闭环输出经坐标变换转为当前车体 `vx/vy` 后进入 `CarRun`。默认采用手册推荐安装，提供安装偏角、传感器中心偏移与航向符号配置；实车校核后调整。

### R6：蓝牙协议

- 保留 `C,<前进>,<左移>,<旋转>\r\n`，仅在开环模式接受，三个量仍为 ±1000 整数。
- 新增 `P,<dx_mm>,<dy_mm>,<dangle_deg>\r\n`，仅在闭环模式接受，支持有符号小数。一次合法帧等同一次位移接口调用；重复帧按重复调用累加，禁止自动重发位置命令。
- 新增 `M,0\r\n`（开环）、`M,1\r\n`（位置闭环）。
- 超长、不完整、错误字段、额外字段、非有限数及非法模式的帧不改变目标/模式，不刷新速度看门狗。
- 开环超过 300 ms 未收到合法速度帧停车；闭环位置命令不使用这个失联计时，不由旧速度看门狗取消。

## Key Decisions

- 本轮用户已确认 A：在固定启动坐标系内累加目标。
- 模式切换不捕获新的位置目标，依据原要求“只有当调用位移函数时，小车目标位置随之变化”。
- 将原仅航向保持控制扩展为默认 X/Y/航向闭环；开环关闭所有纠偏，原手动旋转旁路/松开重捕获行为由显式开环模式替代。
- 相对位置和零点在 MCU 内维护，不发送 OPS 校准、清零或位置更新命令。
- 本轮 PRD、设计和实施计划已完成最终评审；用户在完整方案后回复“继续”，批准实施。

## Risks and Deferred Items

- 实际 OPS 安装方向、中心偏移、航向符号及 X/Y 有效测量需实车确认；有限值检查不能检测始终为零的损坏里程计。
- 位置增益/死区和航向 PD 需实车调参，不承诺仅靠编译即可满足机械精度。
- 当前 CAN 发送可在 FIFO 满时等待 5 ms；OLED 驱动仍为阻塞式，严格周期抖动优化独立处理。
- OPS 丢帧时停止并保留目标；停止期间若发生无法观测的多圈旋转，软件不能还原整圈计数。

## Out of Scope

- 不改 CAN 协议、电机地址、USART2 DMA/IDLE 配置、TIM6 周期、OLED 驱动或手机 App 页面。
- 不加入视觉控制、路径规划、复杂轨迹队列或自动位置帧重传。
- 不自动烧录、驱动车辆或提交已有工作区改动。
